# docs/ai

AI를 어떻게 썼는지 남기는 문서 폴더다. 포트폴리오에서 보여 주려는 것은 도구 이름이 아니라 판단이라서, 무엇을 맡기고 어떻게 검증했고 어디서 AI가 틀렸는지를 기록한다.

## 새 문서를 쓰는 방법

문서 하나에 사례 하나를 담는다. 파일명은 `주제-kebab-case.md`로 한다. 아래 틀을 따르되 비어 있는 항목은 지우지 말고 "없음"이라고 적는다. 해당 사항이 없다는 것도 정보다.

```markdown
# 제목

## 한 줄 요약

## 문제
무엇이 비효율이었거나 위험했는지

## AI에게 맡긴 것과 내가 한 것
역할 경계

## 검증
AI 결과를 어떻게 확인했는지 (테스트, 원본 대조, 교차 확인)

## AI가 틀린 사례
무엇이 틀렸고 어떻게 잡았는지

## 결과
가능하면 숫자로 (시간, 정확도, 비용, 건수)

## 접었거나 남긴 것
시도했다가 그만둔 것과 이유, 아직 안 한 것
```

## 쓸 때 지킬 것

- 근거 없는 수치는 쓰지 않는다. 측정하지 않았으면 측정하지 않았다고 적는다.
- 성공담만 쓰지 않는다. 실패와 오탐 사례가 면접에서 가장 설득력이 있다.
- 문체는 메모하듯 자연스러운 -다체로 쓴다. `~함`, `~됨` 나열은 피한다.
- 실제 사용자 건강 데이터는 문서에 넣지 않는다. 합성 데이터만 쓴다.
